#不定向飛靶成績與日常生活紀錄分析系統

這是一套為「不定向飛靶」選手與教練設計的數據紀錄與分析系統。本系統結合了射擊成績紀錄、日常生活作息追蹤，並導入機器學習（隨機森林演算法）來分析生活因子對射擊表現的影響，最終自動生成建議。

## 特別說明 
1. **測試方式 (雲端)**
   本專案已經部署於 Streamlit Cloud，且已在後端綁定好所有必要的環境變數與安全金鑰，可直接點擊下方「正式上線網站」連結進行測試。
2. **本地端執行**
   若需要在本地端編譯並執行本系統原始碼，我們已經將測試專用的 Google 雲端資料庫金鑰 (`.streamlit/secrets.toml`) 隨附於壓縮檔中。
3. **專案變動**
   雖然最後因效率考量捨棄OCR模型，但我們仍附上OCR模型的程式碼。

## 系統使用指南

本系統分為兩大核心分頁，請透過左側側邊欄進行切換：

### 分頁一：飛靶辨識與上傳
此頁面用於每次訓練或比賽後的數據登錄。
1. **上傳檔案**：可上傳射擊成績單照片（JPG/PNG/PDF）作為視覺核對與預覽。
2. **填寫基本資訊與九方位分析**：輸入選手編號、日期，並透過下拉選單評估九宮格（左上、正中、右下等）的命中狀況（良好/尚可/較差）。
3. **填寫射擊表現**：輸入「總發數」、「二發命中」與「失誤數」，系統將即時防呆並自動推算出「一發命中數」及各項命中率。
4. **填寫日常生活因子**：輸入入睡與起床時間（系統自動計算睡眠時長），並填寫熱身時間、早餐熱量/蛋白質、咖啡因攝取、疲勞與緊張程度。
5. **儲存上傳**：勾選確認無誤後，點擊「資料上傳雲端資料庫」，系統會將資料清洗結構化後，即時寫入 Google Sheets 雲端資料表。

### 分頁二：歷程數據與分析
此頁面為教練與選手的數據儀表板，具備權限管控。
1. **解鎖後台**：在密碼鎖輸入管理員密碼（"Shooting"）解鎖分析看板。
2. **選擇選手**：從下拉選單選擇要分析的選手，點擊「✅ 確認載入」。
3. **歷史資料庫與管理 (Tab 1)**：
   * 檢視該選手所有的歷史詳細數據表。
   * 可透過「日期」與「時間」查找單筆紀錄。
   * 提供「刪除」功能，支援從網頁端直接同步刪除 Google Sheets 上的特定紀錄。
4. **選手數據分析看板 (Tab 2)**：
   * **歷史表現趨勢**：折線圖追蹤長期總命中率變化。
   * **九方位失誤熱區圖**：系統依據歷史失誤率進行加權，繪製出 3x3 的視覺化失誤熱區，一眼看出選手防守弱點（佔比越高越紅）。
   * **交叉分析圖表**：睡眠時長 vs 命中率、緊張程度 vs 失誤率的關聯圖。
   * **AI 專屬生活因子分析**：導入 scikit-learn的隨機森林，找出對該選手命中率影響最大的 Top 3 生活因子，並反推其「最佳表現場次」的平均數值，給出作息建議（例如：建議將咖啡因攝取控制在 120mg）。
